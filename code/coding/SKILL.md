# Coding

Peter's coding philosophy is the standard for any code written or
edited here — his repos, skill CLIs, tests, and one-off scripts
alike. It lives in one place only: read it there, never copy it.

- Read it when the coding work starts, not at session start. Re-read
  when a design choice feels open: function or class, public or
  private, test shape, error shape.
- Local copy first (`local_path` in `config.md`); pull `main` first
  when the last pull is not from today. The web copy (`web_url` in
  `config.md`) is the fallback when the clone is missing or
  unreadable.
- Its exception rule applies as written: a deliberate exception for
  real-world benefit or timing is in keeping with the philosophy,
  not a violation of it.
- Do not edit the philosophy text on Peter's behalf. Changes go
  through the studio1way repo like any other change there, drafted
  in chat first when he asks.
