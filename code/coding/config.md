# Config

Machine values for the coding skill. The philosophy text
itself is never copied into this skill. It lives in the studio1way
repo, and this config only says where to read it.

```yaml
# Primary source: the local clone of the studio1way repo.
local_path: ~/projects/studio1way/src/main/resources/coding-philosophy.md
repo_dir: ~/projects/studio1way
# Fallback source: the same file, served by the site.
web_url: https://www.studio1way.com/coding-philosophy.md
```
